# Professional CV Portfolio

A modern CV website built with Next.js, Tailwind CSS, and TypeScript.

## Features

- Responsive CV template
- Built with Next.js 14
- Tailwind CSS for styling
- TypeScript for type safety
- Clean and professional layout
- Deployable to GitHub Pages

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## GitHub Pages Deployment

1. Create a repository on GitHub
2. Set the repository name as your GitHub username (e.g., `yourusername/yourusername.github.io`)
3. Push your code to the repository
4. Deploy to GitHub Pages:

```bash
npm run deploy
```

Your site will be available at `https://yourusername.github.io`

## Tech Stack

- Next.js 14
- React
- Tailwind CSS
- TypeScript
